Week 1 Day 12 - Security Controls

What is a Security Control?

A security control is a measure used to reduce security risks and protect systems.

Types of Security Controls

Preventive Controls
Prevent attacks before they happen.

Examples:
- Firewall
- MFA
- Strong passwords

Detective Controls
Identify or detect attacks.

Examples:
- Log monitoring
- SIEM alerts
- IDS

Corrective Controls
Help recover after incidents.

Examples:
- Backups
- Incident response
- System restoration

Defense in Depth

Defense in Depth means using multiple security layers instead of relying on a single security measure.

What I Learned Today

- Security controls reduce risk.
- Controls can prevent, detect, or correct security incidents.
- Multiple security layers provide stronger protection.
