Week 1 Day 7 - Linux File System

File

A file stores data such as text, images, videos, or programs.

Directory

A directory (folder) is used to organize and store files and other directories.

Home Directory

The home directory is the personal folder of a user where their files are stored.

Example:
/home/kali

Root Directory

The root directory is the top-level directory in Linux and is represented by "/".

What I Learned Today

- Linux organizes data using files and directories.
- The root directory is the highest level in the Linux file system.
- The home directory stores user files.
- Understanding the file system is important for cybersecurity professionals.
