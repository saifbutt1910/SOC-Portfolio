Week 2 Day 6 - Wireshark Filters

What is a Filter?

A filter helps display only the packets relevant to an investigation, making analysis faster and easier.

Common Filters

DNS
dns

Shows DNS traffic.

HTTP
http

Shows HTTP web traffic.

ICMP
icmp

Shows ping and ICMP packets.

IP Address
ip.addr == 192.168.1.10

Shows all traffic related to a specific IP address.

Why Filters are Important

Filters reduce the amount of data analysts need to review and help focus on suspicious activity.

What I Learned Today

- Wireshark filters simplify packet analysis.
- Different filters help investigate different types of network traffic.
- Using the correct filter speeds up investigations.
