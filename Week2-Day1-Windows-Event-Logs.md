Week 2 Day 1 - Windows Event Logs

What is Event Viewer?

Event Viewer is a Windows tool used to record and view system, application, and security events.

Main Log Categories

Application Logs
Records events generated by applications.

System Logs
Records operating system events.

Security Logs
Records security-related activities such as logins and account changes.

Event IDs

Windows uses Event IDs to identify specific events.

Examples:
- 4624 = Successful Login
- 4625 = Failed Login

Why Event Logs Are Important

Event logs help security teams investigate incidents and identify suspicious activity.

What I Learned Today

- Event Viewer stores important system and security logs.
- Security logs are frequently used during investigations.
- Event IDs help identify specific activities.
