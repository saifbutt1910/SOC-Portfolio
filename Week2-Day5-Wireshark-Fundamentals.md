Week 2 Day 5 - Wireshark Fundamentals

What is Wireshark?

Wireshark is a network packet analyzer used to capture and inspect network traffic.

What is a Packet?

A packet is a small unit of data transmitted across a network.

Common Protocols

HTTP
Port 80

HTTPS
Port 443

DNS
Port 53

ICMP
Used for network diagnostics such as ping.

Why Wireshark is Important

Wireshark helps analysts:

- Investigate network activity
- Identify suspicious connections
- Analyze communication between systems

## What I Learned Today

- Wireshark captures network packets.
- Packets contain information about network communication.
- Wireshark is an important tool for cybersecurity investigations.
