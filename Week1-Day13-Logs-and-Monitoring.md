Week 1 Day 13 - Logs and Monitoring

What is a Log?

A log is a record of events and activities occurring on a system.

Examples:
- User logins
- Failed login attempts
- File changes
- System errors

Why Logs are Important

Logs help security teams understand:
- What happened
- When it happened
- Who performed the action

What is Monitoring?

Monitoring is the process of continuously watching systems and logs for suspicious activity.

Examples:
- Multiple failed login attempts
- Malware detections
- Unusual network activity

What I Learned Today

- Logs record system activities.
- Monitoring helps identify potential security incidents.
- SOC analysts use logs to investigate alerts and threats.
