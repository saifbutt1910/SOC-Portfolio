Week 2 Day 2 - Log Analysis Fundamentals

What is Log Analysis?

Log analysis is the process of reviewing logs to identify useful information, suspicious activity and potential security incidents.

Questions Analysts Ask

Who?
Who performed the action?

What?
What happened?

When?
When did it happen?

Where?
Which system or IP address was involved?

Why?
Does the activity appear suspicious?

Examples of Suspicious Events

- Multiple failed login attempts
- Logins at unusual times
- Unexpected administrator account creation

What I Learned Today

- Logs contain valuable security information.
- SOC analysts investigate logs to identify threats.
- Asking the right questions helps determine if activity is suspicious.
