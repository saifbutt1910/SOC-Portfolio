Week 2 Day 3 - Windows Event IDs

What are Event IDs?

Event IDs are numbers assigned to Windows events to help identify specific activities.

Important Event IDs

4624
Successful Login

4625
Failed Login

4720
User Account Created

4726
User Account Deleted

Why Event IDs Matter

Event IDs help security analysts quickly identify and investigate events.

What I Learned Today

- Windows uses Event IDs to identify activities.
- Login events are commonly investigated by SOC analysts.
- Event IDs help speed up investigations.
