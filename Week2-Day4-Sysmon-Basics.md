Week 2 Day 4 - Sysmon Basics

What is Sysmon?

Sysmon (System Monitor) is a Windows tool that records detailed system activity.

Why Sysmon is Useful

Sysmon provides more visibility than standard Windows logs.

It can record:

- Process creation
- Network connections
- File creation
- System activity

Benefits for SOC Analysts

- Better investigations
- More detailed evidence
- Improved threat detection

What I Learned Today

- Sysmon records detailed system events.
- SOC analysts use Sysmon during investigations.
- Sysmon helps identify suspicious processes and activity.
